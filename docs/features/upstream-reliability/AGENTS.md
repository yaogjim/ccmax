# 上游可靠性 feature 文档规范

本目录按用户于 2026-10-24 确认的实施计划建立，属于内部 feature 过程材料，是 `docs/AGENTS.md` 中过程材料禁入规则的局部例外。

- 仅维护本 feature 的 `prd.md`、`roadmap.md`、`design.md`、`plan.md`，统一使用简体中文，无须建立公开英文镜像。
- 使用 `REL-*` 需求编号关联四份文档；PRD 管需求，roadmap 管顺序，design 管契约，plan 管执行与证据。
- 本目录不得进入公开站点索引、正文、搜索、sitemap 或静态页面；不得新增公开导航。
- 记录源码事实、历史报告、实验、推断和未运行项目的区别，不将计划或代码存在写成运行通过。
- 禁止复制真实用户历史、会话标识、凭据或本机绝对路径。持久化与权限安全规则继续适用。
