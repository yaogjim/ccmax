# ccmax v0.6.8

本次带来 **团队计划**、**会话协作** 与 **侧边追问** 三项协作能力，补全 **本地定时任务** 的完整链路（创建、执行、通知、停止、清除），并新增 **系统设置页** 统一管控可选功能入口。本版本起仅提供 macOS（Apple Silicon）安装包。

> **重要**：本仓库为个人维护的分支版本，安装包使用本地自签名证书构建（非 Apple Developer ID，未公证）。首次打开需按下方「安装」一节的说明解除 macOS 隔离标记，属正常现象。

## 核心功能

- **团队计划**：Agent Teams 在启动前先生成结构化团队计划（成员、预设、模型、任务归属与依赖），以计划卡形式呈现，确认后按计划启动，支持团队整体关停。
- **会话协作**：新增跨会话消息信封与鉴权，会话之间可以引用与协作；桌面端提供会话引用详情与工具链接渲染。Agent 之间的通信不构成用户授权，权限边界保持清晰。
- **侧边追问**：`SideChatSurface` 独立问答面板，在主会话旁开一条临时问答线，不打断当前任务。
- **会话引用**：会话引用上下文与持久化，引用详情、工具链接组件齐备。

## 定时任务与本地自动化

- **运行记录可停可清**：运行列表新增「停止」（运行中）与「清除」（终态，二次确认）操作；停止按 runId 精确终止，过期界面点击不会误杀新一轮运行；删除任务前先落定运行中的进程并清理历史记录。
- **可靠性修复**：崩溃残留的运行记录按执行锁在每个调度 tick 落定，不再永久卡在 running；手动运行区分 busy / failed / timeout 结果；子进程 stdout / stderr 并发读取，管道不再无限挂起执行锁；启动超时返回 503。
- **自然语言任务管理**：新增本地定时任务与消息发送工具，Agent 可经本地 server API 创建、列出、启停、立即执行任务；认证 token 不进入模型参数、日志或 Bash 环境。
- **通知投递链路**：统一收件人解析（Telegram 私聊 / 群聊、飞书 open_id / chat_id），目标仅来自已授权配对；投递记录先落盘、重启恢复不重复入队、幂等键去重；Telegram 限流退避重试，区分明确失败与超时不确定态。Telegram 投递校验 message_id 回执，无有效回执记为 indeterminate，不虚报送达。
- **任务管理 UI**：任务行启停 / 删除 / 立即执行等待 API 结果，显示进行中与失败原因；新建 / 编辑支持通知目标选择。

## 系统设置页

- 设置导航新增固定「系统」页，统一控制终端、IM 接入、宠物、Trace、诊断、技能市场与 H5 访问等可选入口的显示。相关项默认隐藏，隐藏后导航与直接入口统一回到系统页。
- 侧栏技能市场支持开关与自定义地址。
- 服务商新建时默认选中「自定义」，并移除 atlas cloud、TeamoRouter、玄枢 API、FennoAI、七牛云 AI 等预设。

## 模型与供应商

- 新增 OpenAI / Grok 官方账号的模型设置页，模型目录校验与 opus 4.5 配置；请求兼容性字段增强。
- 模型选择器补齐已配置的 Fable 槽位模型。
- Claude 流完整性与计费回归改进，重试与错误呈现优化。

## 桌面端与适配器

- 虚拟列表高度缓存、composer 编辑器 / 建议 / 引用菜单改进；工作区文件树、启动器、标签栏与快捷键增强；删除旧版连续聊天历史实现，由统一会话投影替代。
- 诊断页新增「提交诊断」向导对话框，按步骤收集并打包诊断信息。
- IM 适配器：会话恢复与 chat-runtime 改进；Telegram 命令路由与会话选择修正；飞书 legacy 会话入口；钉钉 / 微信 / WhatsApp 适配更新。
- 无语言偏好的新用户默认简体中文。

## 安装

本版本仅提供 **macOS Apple Silicon（ARM64）** 安装包，要求 macOS 12.0 及以上：

- `ccmax-0.6.8-mac-arm64.dmg` — 安装包
- `ccmax-0.6.8-mac-arm64.zip` 及 `.blockmap` — 增量更新用
- `latest-mac.yml` — 自动更新元数据

**关于签名**：安装包由本地自签名证书 `cu-helper-dev` 构建，宿主、后台服务与 Computer Use 助手共享同一证书签名链，Computer Use 功能可用；但未经 Apple Developer ID 签名与公证，首次打开会被 Gatekeeper 拦截（提示「已损坏」或「无法验证开发者」）。两种解除方式任选其一：

1. **推荐**：从 Assets 下载 `install-macos-unsigned.sh`，与 DMG 放在同一目录，执行 `bash install-macos-unsigned.sh`，脚本会安装应用、移除隔离标记并启动。
2. **手动**：正常安装 DMG 后执行 `xattr -dr com.apple.quarantine /Applications/ccmax.app`，再打开应用。

Windows 与 Linux 构建本版本不提供。

# ccmax v0.6.8

This release brings **team plans**, **cross-session collaboration** and **side chats** to agent teams, completes the **local scheduled-task** pipeline (create, run, notify, stop, clear), and adds a **System settings page** that centrally controls optional feature entries. Starting with this version only macOS (Apple Silicon) installers are published.

> **Important**: this repository is a personally maintained fork. Installers are built with a local self-signed certificate (not an Apple Developer ID, not notarized). The first launch requires clearing the macOS quarantine attribute as described in "Installation" below — this is expected.

## Highlights

- **Team plans**: before an Agent Teams run starts, a structured team plan (members, presets, models, task ownership and dependencies) is generated and presented as a plan card; the team starts only after you confirm, and can be shut down as a whole.
- **Cross-session collaboration**: cross-session message envelopes with authentication let sessions reference and collaborate with each other; the desktop renders session-reference details and tool links. Agent-to-agent communication never constitutes user authorization.
- **Side chats**: an independent `SideChatSurface` panel opens a temporary Q&A thread beside the main session without interrupting it.
- **Session references**: session-reference context and persistence, with reference-detail and tool-link components.

## Scheduled tasks and local automation

- **Runs can be stopped and cleared**: the run list gains Stop (while running) and Clear (terminal state, with confirmation); stop terminates by runId so a stale UI click cannot kill a newer run; deleting a task settles its in-flight runner and clears history first.
- **Reliability fixes**: crash-orphaned run records are settled per execution lock on every scheduler tick instead of stuck at running forever; manual runs distinguish busy / failed / timeout; child-process stdout / stderr are read concurrently so pipes no longer hang the execution lock; startup timeouts return 503.
- **Natural-language task tools**: new local scheduled-task and message-send tools let the agent create, list, toggle, and run tasks through the local server API; auth tokens never enter model arguments, logs, or the Bash environment.
- **Notification delivery**: unified recipient resolution (Telegram private chats / groups, Feishu open_id / chat_id), targets restricted to authorized pairings; delivery records persist before sending, survive restarts without re-enqueueing, and deduplicate via idempotency keys; Telegram backs off on rate limits and distinguishes definite failure from timeout-indeterminate. Telegram delivery verifies message_id receipts; a missing receipt is recorded as indeterminate, never as delivered.
- **Task management UI**: row actions wait for API results and surface progress and failure reasons; create / edit support notification-target selection.

## System settings page

- A fixed "System" page in settings controls the visibility of optional entries: terminal, IM access, pet, Trace, diagnostics, skill market and H5. They are hidden by default; hidden entries fall back to the System page everywhere.
- The sidebar skill market supports a toggle plus a custom address.
- New providers default to "Custom", and the atlas cloud, TeamoRouter, Xuanshu API, FennoAI and Qiniu AI presets were removed.

## Models and providers

- New model-settings panels for official OpenAI / Grok accounts, with model-catalog validation and opus 4.5 configuration; request compatibility fields improved.
- The model selector now includes configured Fable-slot models.
- Claude stream-integrity and billing regression improvements, with better retries and error rendering.

## Desktop and adapters

- Virtual-list height caching, composer editor / suggestion / reference-menu improvements; workspace file tree, launcher, tab bar and shortcut enhancements; the legacy continuous chat history implementation was removed in favor of a unified session projection.
- The diagnostics page gains a "Submit diagnostics" wizard dialog that collects and packages diagnostics step by step.
- IM adapters: session-recovery and chat-runtime improvements; Telegram command routing and session-selection fixes; Feishu legacy session entry; DingTalk / WeChat / WhatsApp adapter updates.
- New users without a language preference default to Simplified Chinese.

## Installation

This version ships a **macOS Apple Silicon (ARM64)** installer only, requiring macOS 12.0 or later:

- `ccmax-0.6.8-mac-arm64.dmg` — the installer
- `ccmax-0.6.8-mac-arm64.zip` and `.blockmap` — for incremental updates
- `latest-mac.yml` — auto-update metadata

**About signing**: the build is signed with the local self-signed certificate `cu-helper-dev`; the host, sidecar and Computer Use helper share one signing chain, so Computer Use works. However, without an Apple Developer ID signature and notarization, the first launch is blocked by Gatekeeper ("damaged" or "cannot verify developer"). Either:

1. **Recommended**: download `install-macos-unsigned.sh` from the Assets into the same folder as the DMG, then run `bash install-macos-unsigned.sh`; it installs the app, removes the quarantine attribute, and launches it.
2. **Manual**: install the DMG as usual, run `xattr -dr com.apple.quarantine /Applications/ccmax.app`, then open the app.

Windows and Linux builds are not published for this version.
