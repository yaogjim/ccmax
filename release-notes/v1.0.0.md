# ccmax v1.0.0

本次为 1.0 里程碑版本：完整集成上游 v0.7.0 大改版——桌面端整体换上全新的「素 Porcelain」视觉系统，手机和平板 H5 按触屏重做，输入框「+」菜单重新组织为技能 / 连接器 / 运行方式三组，新增「编辑已发送的提示词并重跑」和会话「轨迹」视图。Agent Teams 的可靠性和后台任务的收尾做了系统性修复。同时修复了集成过程中发现的启动迁移顺序与关闭竞态问题。

> **安装范围与签名**：本版本仅提供 macOS Apple Silicon（ARM64）安装包，沿用该分支的本地自签名方式，未经 Apple Developer ID 签名和公证。首次打开可能被 Gatekeeper 拦截，请仅在确认来源可信后按下方步骤安装。Windows、Linux 和 Intel Mac 安装包不在本次发布范围内。

## 素 Porcelain 视觉系统

- 所有页面重做在同一个视觉系统上：浅色主题、工具调用读成时间线、用户消息用气泡、输入框是悬浮卡片。
- 六个主题统一圆角（4/6/8/12/16/20）和字号（11/12/13/14/15/18/22/26）阶梯，字重不超过 semibold；状态色按语义取（运行中 = info、等待 = warning、完成 = success、失败 = error）；图标全部来自 lucide。

## 手机与平板 H5 重做

- 抽屉式布局换成单层导航栈，首页是按状态分组的会话列表（「等你处理」置顶），系统返回手势回上一层。
- 输入框只留一行（+ / 模型 / 发送），其余收进「+」底部面板；审批、提问和计划直接占用输入框位置，不再弹窗遮挡；消息长按出菜单。
- 首页右下角悬浮「新任务」，点开从底部升起全屏卡片；平板保留左列表右详情。

## 输入框「+」菜单重组

- 一级分为「给这次任务用」（技能 / 连接器 / 文件）和「运行方式」（Agent Teams、操作电脑两个开关），其余进「更多工具」。
- 连接器按「已连接 / 需要处理 / 推荐」列出并显示各自 logo；技能列出最近用过、全部技能和可一键安装的市场热门。

## 编辑已发送的提示词并重跑

- 悬停已发送的提示词出现「编辑并重发」，气泡变成内联编辑器；发送前会先试算回滚、在影响后续轮次或文件时确认，然后原地重跑；回滚失败不改动任何东西并保留草稿。
- 当前无法编辑时（轮次运行中、有后台任务、检查点加载中）按钮保持可见并给出禁用原因。

## 会话「轨迹」视图

- 会话头部新增聊天 / 轨迹切换。轨迹是每行一个事件的高密度账本（系统提示、用户消息、注入的上下文、助手回复、工具调用），配三轨小地图、按轮折叠、搜索和逐行详情面板，也能钻进子 Agent。
- 设置里原来的 Trace 列表、trace 标签页和独立窗口取消，已保存的 trace 标签会迁移成会话标签。

## 安全的数据目录迁移

- 在「设置 → 通用」更改数据目录不再直接搬文件，而是走暂存 → 校验 → 迁移凭据 → 重启的流程，写迁移日志以便中断后恢复；同时会先让 IM sidecar 停稳再动盘。
- 迁移校验激活期间不会提前创建新目录；校验通过后才启动通知投递对账。

## 语音听写

- 录音时工具栏整行变成录音条：取消、麦克风滚动痕迹、最后 15 秒倒计时、停止和发送；语音输入默认开启（已保存过 `false` 的保持不变）。

## Agent Teams 可靠性

- **长任务可恢复**：成员回合被截断的流自动重发；服务端托管成员，停下的成员收到消息后从自己的 transcript 重启，瞬时失败按 15s/45s/2m/5m/10m 自动续跑；邮箱改为原子写入、按身份标记已读。
- **停止后保持停止**：按下停止后队长不再继续轮询邮箱，队员在停止前发出的汇报不会偷偷把团队唤醒，只有用户的下一条消息能解除。
- **强制执行任务依赖**：依赖未完成的成员只在依赖就绪时才收到指令；TaskUpdate 拒绝队员在依赖未完成时开始或完成自己的任务；每个成员会被告知谁在等它的结果，并在完成前把结果发过去。
- **成员任务状态**：成员停下或失败后任务不再显示「进行中」动画；成员抽屉把任务分成「当前 / 下一个 / 已完成」，标出被阻塞任务缺哪个依赖。

## 后台任务与运行时

- 按停止会一并收掉本会话的后台 shell 任务（`run_in_background`、Dream、workflow），不再只断前台轮；没有客户端、只靠后台任务续命的会话有 31 分钟硬上限。
- 桌面没运行过的会话（其他 CLI 跑完的）里，后台任务不再永久「运行中」；没有 CLI 进程时，停止一个只存在于历史里的任务会收敛为已停止而不是报错。

## 模型与供应商

- **OpenAI Chat 代理默认发图**：不再按主机名和模型名猜图片能力，图片一律先发给模型；上游明确拒绝图片输入时去掉图片重发一次，只有这次成功才把该端点和模型记为纯文本 30 分钟。
- **新会话默认推理强度改为 low**：服务端和桌面 store 的全局默认都从 max 调到 low，已保存过偏好的人不变。

## 修复

- **中文文件名被截断**：正文和内联代码里的中文文件名按整个 token 读取，`测试文档1.docx` 不再变成 `1.docx`；无法自行界定的名字交给磁盘确认，优先取最长的已存在文件。
- **不存在的图片报红卡**：文件路由返回 400/403/404/413 时视为图片本就不存在，内联卡片静默消失、Markdown 图片退回 alt。
- **硬编码文案没走翻译**：组件里直接写死的界面文字接入 `t()`，补齐五个语种；`untranslatedText.test.ts` 扫描所有组件防止回退。
- **provider 流中断的报错**：上游提前关闭 200 流且重试失败时，错误指明是上游模型供应商的问题、明确不是上下文超限，并记录证据（事件数、stop_reason、重试次数等）。
- **文件卡片和链接乱弹**：回复里只是「提到」的路径不再当成产出的文件；输出卡片需要本回合确实产出过该文件，链接要等磁盘确认存在且被改过才渲染。
- **会话查找每次全量解析**：只有一个候选文件时不再解析整个 transcript，长会话分页重开的开销不再随文件大小平方增长。
- **工作区浏览器改用 `<webview>`**：网页放进会话面板内，其他页面、菜单和弹窗能正常盖在上面。
- **其他**：非整数缩放时消息列表占位高度稳定；技能市场首页回到同一页面表面；Agent Teams 头部窄栏换行排布；空白会话不再显示侧边聊天入口；自定义 provider 预设按当前语言显示；token 用量页支持按用量、活动、模型排序。

## ccmax 集成修复

- **启动迁移顺序**：旧品牌目录导入先于索引和公共 Telegram 启动，迁移校验期间不读取投递存储、不创建 fork 所属目录，校验通过后补跑通知投递对账。
- **关闭竞态**：注入关闭团队提示前重新读取 roster，避免向已不存在的团队多花一轮模型调用；保护停止后的异步启动并同步清理退出时的 CLI 子进程；团队关闭提示只注入一次，保留收尾邮箱处理。
- **回归测试稳定化**：cron launcher 夹具、skills providers 写入路径、storageMigrationMetadata 临时根规范化、officeZipGuard 与 VoiceTrail 用工作量计数/假时钟替代挂钟断言等。

## 安装与更新

- macOS Apple Silicon：下载 `ccmax-1.0.0-mac-arm64.dmg`，打开后拖入「应用程序」。
- 首次打开若被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」中点「仍要打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/ccmax.app`。
- 已安装 v0.6.x–v0.11.x 的用户可直接用新 DMG 覆盖安装，配置、订阅、会话与定时任务数据保持不变。
